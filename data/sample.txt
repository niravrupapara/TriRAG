PAGE 21: Reciprocal Rank Fusion

Reciprocal Rank Fusion combines multiple ranked lists using the reciprocal of a document's rank. A common formulation adds 1 divided by k plus rank for each retrieval system in which the document appears. The approach is useful because ranking positions are comparable even when the underlying retrieval scores are not.

PAGE 22: Cross Encoder Reranking

A cross-encoder receives a query and candidate document together and produces a relevance score. Because both texts are processed jointly, the model can capture fine-grained interactions between query terms and document content. The trade-off is computational cost, so reranking is usually applied only to a small candidate set.
